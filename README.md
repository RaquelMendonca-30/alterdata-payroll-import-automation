# Automação Importação Folha Alterdata

## 📌 Sobre o projeto

Sistema desenvolvido em Python para automatizar a conversão de planilhas de folha de ponto em arquivos TXT compatíveis com importação no sistema Alterdata.

## 🚀 Problema resolvido

Antes, os lançamentos eram feitos manualmente, consumindo tempo e aumentando risco de erro operacional.

Com esta solução, o processo foi automatizado, reduzindo horas de trabalho para poucos minutos.

## ⚙️ Funcionalidades

- Leitura automática de planilhas Excel
- Conversão de horas e valores monetários
- Geração de arquivo TXT no layout exigido
- Tratamento de dados e validações
- Redução de erros manuais

## 🛠 Tecnologias utilizadas

- Python
- Pandas
- Excel
- Automação de processos

## 📈 Impacto

- Ganho de produtividade
- Escalabilidade operacional
- Maior confiabilidade no processo
